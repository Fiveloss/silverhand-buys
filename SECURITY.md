# Security

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository. We will reply as soon
as we can and credit you in the fix unless you prefer otherwise.

Things we especially want to hear about:

- a way to make the bot post someone else's text, links or prices in a chat;
- a way to change a chat's settings, or claim a paid plan, without being an admin or paying;
- anything that makes the bot show a wrong amount, buyer or market cap for a real trade.

## What the bot will never do

The bot never asks for private keys or seed phrases, never asks you to connect a
wallet and never trades. Any account that asks for these in its name is a
scammer. Please report it to Telegram.
